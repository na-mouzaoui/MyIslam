# Zellige background

The patterns in this folder come from the open-source project
[evoluteur/islamic-patterns](https://github.com/evoluteur/islamic-patterns)
(MIT license, © 2026 Olivier Giulieri).

- Tiling: `4.8.8` (octagons and squares), contact angle `67.5°`,
  line style `interlace`, 720 × 720 export.
- Recolored for MyIslam: `#123C32` on `#F6F3E9`.
- `zellige-night.svg` is a line-only cream variant for the dark headers.
- `zellige-transparent.svg` is the same tile without its ivory base,
  used over the welcome card.

The project generates the patterns with Hankin's "polygons in contact"
method (E. H. Hankin, 1925; formalized by Craig S. Kaplan, 2005).
